# Phaser starter

A small Phaser 4 game using the curated `phaser@4.2.1` platform module: tap the falling orbs. It
calls `Prototir.ready()` once the game boots, sends an event per catch and reports the score when a
round ends. The import map is created from `prototir.json` during upload. ZIP this folder's
contents and upload them to Prototir.
