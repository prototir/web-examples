# PixiJS starter

Draggable shapes with PixiJS 8, using the curated `pixi@8.6.0` platform module (import it as
`pixi`). It calls `Prototir.ready()` once the canvas is up and sends an event per drop. The import
map is created from `prototir.json` during upload. ZIP this folder's contents and upload them to
Prototir.
